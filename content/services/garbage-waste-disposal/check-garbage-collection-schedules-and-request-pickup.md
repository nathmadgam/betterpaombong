# Check Garbage Collection Schedules and Request Pickup

Paombong-specific details for this service are still being gathered by volunteers.

Until this page is complete, the office to ask is:

- **Municipal Environment and Natural Resources Office (MENRO):** (044) 769-4569. 2nd floor, Main Building, Municipal Hall.

The office's [Citizen's Charter](https://paombong.gov.ph/wp-content/uploads/2026/04/MENRO-Citizen_s-Charter.pdf) lists garbage collection. To request a collection, it asks for a letter addressed to the MENRO and a photo that shows the garbage and where it is. It does not publish a collection schedule, so please ask the office.

For every other office, see [municipal offices and contact numbers](../../government/departments/municipal-offices).

Know how this works in Paombong? [Help write this page](https://github.com/nathmadgam/betterpaombong).
